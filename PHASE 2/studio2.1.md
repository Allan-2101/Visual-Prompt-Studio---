Visual Studio 2.1 : Exploring Medium Through Prompt Variation

MEDIUM A:
Create an artwork that uses oil painting on canvas style and emphasizes layering and glazing, value, lines and depth of color blending for a typical Arabian night which looks a bit more like dusk, in a busy plaza overflowing with street vendors and animals like camels, cats, horses, in a way that it’s chaotic but still feels like home. The Sky should be a dark navy blue with stars, but the main area of the plaza should still be slightly lit up by the glow of the dusks last dying light.

The Sky should be a dark navy blue with stars, but the main area of the plaza should still be slightly lit up by the glow of the dusks last dying light.
